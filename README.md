## Hola, soy César Rodríguez

Desarrollador enfocado en **integración de IA** y **desarrollo web**. Construyo sistemas que
usan modelos de lenguaje dentro de procesos reales: lectura de documentos con visión,
asistentes con RAG y recomendadores en los que la IA explica, pero las reglas del negocio
deciden.

En **TEDE Consultores** desarrollé sistemas en producción para clientes de salud y de
arrendamiento financiero, desde la base de datos hasta la interfaz y el despliegue.

### Stack principal

- **IA:** OpenAI API (chat, visión, embeddings, salidas JSON estructuradas), RAG con ChromaDB y Pinecone
- **Backend:** PHP 8, Node.js
- **Datos:** MariaDB / MySQL, PostgreSQL, Supabase
- **Frontend:** JavaScript, TypeScript, HTML y CSS sin frameworks, React / Next.js
- **Despliegue:** Apache / LiteSpeed en hosting compartido, Vercel, Docker
